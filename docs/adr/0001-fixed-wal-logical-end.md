# 固定長WALファイルとCRC付き論理終端

Status: accepted for new server databases (2026-10-30, C34; existing metadata v1 remains unchanged)

## 背景

従来のWALは追記ごとにファイルサイズが変わる。比較環境のext4/NVMeで
fdatasyncが約0.1–3msと大きく変動し、更新のp95/p99とスループットを制限した。
単純なゼロ埋め先行確保は、CRC破損を未使用領域と取り違えるため採用しない。

## 方式

新規のサーバ用WALに限り、セグメントの物理サイズをS+64に固定する。
[0,S)は従来のLSNデータ領域であり、v6レコードとLSNは変えない。
末尾64バイトに32バイトの論理終端スロットを2個置く。
各スロットはbig-endianのmagic(u32)、segment index(u64)、generation(u64)、
logical end(u64)、CRC32C(u32、先頭28バイト対象)を持つ。
初期化は新規データ領域をゼロで実体化し（fallocateだけの未書込extent変換を避ける）、
両スロットをgeneration=0/end=0で同期してからレコードを書き始める。
force修復と論理truncateは既存データ領域をゼロ化しない。

同期はデータのpwrite、次世代の終端スロットのpwrite、fdatasyncの順に行い、
成功後だけDurableLSNを進める。世代を交互に書き、通常の二世代は隣接し、
新しい終端は古い終端以上である。pre-roll時も旧セグメントの終端は実データ末尾を
保つ。回復時はCRC付き終端と走査位置が完全一致し、次セグメントも存在する場合
だけ未使用suffixを飛ばす。終端より前のゼロはpaddingとして扱わない。
これにより次セグメントの先頭をレコード境界に保ち、既存のrecycle契約を維持する。
roll時は旧セグメントの実データ終端までの耐久性を確認し、
新セグメントの初期化・ファイル同期・directory同期を済ませてから使用する。
O_APPENDは解除し、Linuxのpwriteが追記にならないようにする。

終端スロットの片方でもCRC・世代・位置・長さが不正なら既定起動は失敗する。
古い正常スロットへ自動的に戻すと、ACK済みレコードを隠す恐れがある。
--forceの場合だけ、既存データ領域全体を候補としてCRC走査し、正常な接頭部へ
論理的に切り詰める。フレームの論理終端以下のゼロもデータ破損として扱う。

## 互換性と影響

.log.metaは従来の20バイト構造を保ち、version=2で固定長方式を示す。
version=1の既存WALは自動変換せず、既存の追記方式と回復方針を維持する。
version=2はbase-onlyでも保存済みSが優先される。旧バイナリはversion=2を
拒否するため、新規WALを旧バイナリで開くことはできない。
組込みDatabase/Loggerは明示指定で新方式を選び、サーバは新規作成時に選ぶ。
再オープンは呼出側の指定にかかわらず保存済み方式を使う。
物理確保は1セグメント分先払いし、logical truncateは物理サイズを縮めない。
WAL-before-data、own/observed commitの同期バリア、recycle floorは維持する。

## 採用条件

論理終端の破損・sync失敗・roll・truncate・再起動・ARIES回復のテスト、
全ctest、oracle検証を通し、同じ耐久性条件のPG比較を保存してから採否を決める。

## 採用記録（2026-10-30）

新規server DBの既定方式として採用する。既存metadata v1を自動変換せず、
埋込みDatabase/Loggerの既定も変更しない。旧バイナリがv2を拒否することを
互換性上の制約として明示する。これはローカル実装の採用記録であり、既存の
利用者DBを移行したという記録ではない。

C34で全4,178テスト・失敗0（既存skip 3）、SQL oracle 602秒771入力・不一致0、
同じ同期commit条件のPG比較を保存した。標準フル比較と精密再測定の結果は
[最終レポート](../postgresql_twofold_results_2026-10-30.md)を参照する。
固定長化単独の寄与は他の変更・I/O変動と分離していないため、比較全体の改善率を
この形式だけの効果とは主張しない。WAL-before-dataとD4 barrierを省略しないこと、
既存形式の維持、破損時の既定fail-stopを採用条件として継続する。
