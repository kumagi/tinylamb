# 検証済みパターンコードを異なる行・実行間で共有する

## モデル上の証明

`TinylambOpt.Research.RegexCacheVersion.regex_cache_version_sound` は、整合した初期キャッシュと任意の要求列に対して、モデル上のディスパッチ結果が参照 API のマッチ位置・置換結果・エラーと一致することを証明している。

## モデルと適用条件

キーに構文、フラグ、照合順序、キャプチャの要否を含める。未対応パターンの fallback と空一致後の進行を定義する。

## 回帰例

同じパターン文字列を存在検索と置換で共用した結果、後者で未参加キャプチャが空文字に化ける。

## 完了条件

モデルではパーサとコードの橋渡し、および任意の cache hit/miss 列の等価性を証明済み。実際の各対応文法・実装との対応確認は残る。

実装との照合先は [common/regex_guard.hpp](../../../common/regex_guard.hpp)。
