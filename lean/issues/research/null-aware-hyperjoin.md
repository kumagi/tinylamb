# NULL を含む循環結合を trie の交差で列挙する

## 証明済みの命題

三角形結合の変数順探索が、重複付き三つの関係を通常の SQL 内部結合で合成した bag を返す。

## モデルと適用条件

辺ごとの SQL 等号と NULL 安全等号を区別し、葉の重複度は三辺の出現数の積とする。

## 回帰例

同じ三角形に辺が 2、3、4 回存在すれば 24 行。一律 NULL 除外は NULL 安全な辺で壊れる。

## 完了条件

変数順の置換に対する結果不変性と、三角形がない場合の中間行の非実体化を示す。

実装との照合先は [plan/cascades.cpp](../../../plan/cascades.cpp)。
